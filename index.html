Contexto del Negocio & Objetivo

Contexto

Preparación y transformación de datos de comercio exterior para construir una base confiable de exportaciones de empresas de la provincia de Santa Fe a partir de reportes descargados de Softrade con inconsistencias, problemas de codificación y tildes.

Objetivo del Proyecto

Construir una base consolidada, limpia y consistente aplicando procesos reproducibles de filtrado, validación y transformación.

Pregunta de Negocio

¿Cuál es el perfil exportador de las empresas santafesinas y qué características de sus exportaciones pueden identificarse a partir de la información de comercio exterior?

Proceso de Trabajo (Paso a Paso)

Preparación de Datos

Ejecución de 2 notebooks de Python en VS Code con pandas, unidecode y openpyxl.

Conversión a mayúsculas, mapeo de variantes de escritura y consolidación de 81 archivos en Base_Unificada.xlsx.

Uso de archivo auxiliar Empresas modificadas.xlsx para resolver casos con casas matrices en otras provincias.

Bloque A: Algoritmo de Filtrado y Unificación de 81 Archivos Excel

Procesamiento iterativo de datasets descargados de Softrade, depuración de localidades y consolidación masiva:

python unificacion_81_archivos.py 
# --- Procesamiento y unificación de archivos Excel ---
archivos = [f"{i}.xlsx" for i in range(1, 82)]
bases_filtradas = []

for archivo in archivos:
    try:
        expos = pd.read_excel(archivo)
        expos["Localidad"] = expos["Localidad"].astype(str).str.upper()
        expos["Localidad"] = expos["Localidad"].replace(mapeo_localidades)
        expos_filtrado = expos[expos["Localidad"].isin(localidades_validas)]
        bases_filtradas.append(expos_filtrado)
    except Exception as e:
        print(f"⚠ Error con {archivo}: {e}")

base_final = pd.concat(bases_filtradas, ignore_index=True)
base_final.to_excel("Base_Unificada.xlsx", index=False)

Bloque B: Función de Clasificación por Sector según NCM (Primario, MOA, MOI, Energía)

Clasificación automatizada de productos según posición arancelaria NCM-SIM:

python clasificacion_ncm.py 
# --- Clasificación automatizada de productos según NCM ---
def clasificar_producto(ncm):
    try:
        limpio = ''.join(filter(str.isdigit, str(ncm)))
        if limpio.startswith(("01", "02", "03", "07", "08", "10", "12", "13", "25", "5201")):  
            return "Primario"
        elif limpio.startswith(("28","29","30","31","32","33","34","35","36","38","39","40","42","43","44","45","47","48","49","56","57","58","59","61","62","63","65","68","69","70","71","72","73","74","76","80","81","82","83","84","85","86","87","90","92","94","95","96","97")):
            return "MOI"
        elif limpio.startswith(("04","05","09","11","15","16","17","18","19","20","21","22","23","41","5202","5205")):
            return "MOA"
        elif limpio.startswith("27"):
            return "Energía"
        else:
            return None
    except:
        return None

Exportaciones_2025["Sector"] = Exportaciones_2025["NCM-SIM"].apply(clasificar_producto)

Automatización del Proceso de Facturación

Automatización con Python de un proceso mensual de facturación

Un flujo repetitivo y propenso a errores de tipeo se transformó en un proceso automatizado, reduciendo el tiempo de trabajo de 60 minutos a 5 minutos.

60 min → 5 min Tiempo de procesamiento
12× Reducción del tiempo de procesamiento

El desafío

La facturación se realizaba al cierre de cada mes y debía resolverse junto con otras responsabilidades.

  • La carga rápida de datos podía generar errores de tipeo.
  • Los nombres de algunas empresas clientes se ingresaban incompletos o con variaciones.
  • La revisión y corrección manual hacía que el proceso demandara cerca de una hora.
Datos de origen → Revisión manual → Correcciones manuales → Excel de facturación

Cómo lo resolví

01

Comprender el flujo de trabajo

Identifiqué la fuente de datos, la estructura de la base y el proceso de facturación existente.

02

Analizar los datos

Usé Python para inspeccionar la base e identificar inconsistencias en los nombres de clientes.

03

Estandarizar los registros de clientes

Observé que las dos primeras letras de cada nombre se mantenían correctas y utilicé startswith() para agrupar los registros por cliente.

04

Generar el archivo de facturación

Creé scripts de Python para dar formato a los datos según los requisitos del cliente y generar el archivo final de facturación en Excel.

Una regla simple para unificar nombres

La coincidencia por prefijo permitió reunir variantes del nombre de un mismo cliente antes de generar la facturación.
